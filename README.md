# Tồn kho các chi nhánh – Natcom

Tool HTML một file (chạy offline) và bản Google Apps Script để theo dõi tồn kho 8 chi nhánh và kho công ty.

- Dùng thử trực tiếp (GitHub Pages): https://luuducthang2027-bit.github.io/tonkhoNatcom/
- `dist/Ton_kho_cac_chi_nhanh.html`: bản chạy offline, mở bằng trình duyệt.
- `dist/AppsScript/Code.gs` và `Index.html`: dán vào Apps Script, triển khai Web App; phiên lưu trên Google Sheet (tab PhienChung).
- `src/core.js`: lõi tính toán; `src/tpl2.html`: giao diện; `src/build.py`: dựng hai bản trên.

Lưu ý: dữ liệu tồn kho thật không nằm trong repo.
